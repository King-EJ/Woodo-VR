WOODO VR  -  VR mod (Unity 6000.0, IL2CPP x64, URP, BepInEx 6)
================================================================
Version 0.1.11 (test build)

INSTALL
  1.unzip to game folder, only tested with virtual desktop XR,
    to disable Mod rename winhttp.dll to winhttp.dll.bak
  2. Start your OpenXR runtime first (Virtual Desktop / SteamVR / Quest Link), then the game.
  

VIEW
  * You are where the game's camera is and see the diorama in 3D; your view turns with the game camera.
  * The game's HUD / object panel is a see-through layer lined up exactly with the camera's picture, so whatever
    the laser points at - a piece in the panel or a spot in the diorama - is where the mouse is.
  * Menus / pause: the game's picture on a solid screen in front of you.

CONTROLS (the controllers are the mouse + keyboard)
-
  Right controller laser .. the mouse pointer
  
  Right trigger ........... left mouse (click, hold to drag pieces)
  
  A ... left mouse too
  
  Right grip .............. right mouse 
  
  B ... right mouse
  
  Left trigger ............ right mouse
  
  Right stick ............. turn the camera around the diorama (right mouse drag)
  
  Left stick up / down .... zoom (mouse wheel)
  
  Left grip + left stick .. pan the camera (middle mouse drag)
  
  Right stick click ....... middle mouse
  
  Y ....................... Tab
  
  X + Y together ... Esc (pause)
  
  Left grip + Y ........... VR SETTINGS MENU (stick up/down choose, left/right change, A toggle, B close)
  
  Left grip + X ........... **re-centre the view**
  
  Every button can be changed in the config ([Controls], Unity key names; Mouse0/1/2 = left/right/middle mouse).
